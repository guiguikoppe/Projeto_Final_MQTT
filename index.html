PROJETO IoT

Monitoramento Ambiental em Tempo Real

Uma solução IoT desenvolvida para coletar dados ambientais utilizando sensores conectados a um ESP32 e transmitir essas informações em tempo real para uma interface Web.

01 — SOBRE

O que é o projeto?

Este projeto apresenta uma solução completa de Internet das Coisas (IoT) capaz de monitorar condições ambientais através de sensores conectados a um microcontrolador ESP32.

Os dados de temperatura, umidade e qualidade do ar são coletados periodicamente e enviados através do protocolo MQTT para um servidor Mosquitto.

Posteriormente, os dados são recebidos por uma página Web através de WebSockets, permitindo o acompanhamento das informações em tempo real.

OBJETIVO

Conectar o mundo físico ao digital.

Sensores coletam informações do ambiente e o sistema transforma essas informações em dados acessíveis através da Web.

02 — HARDWARE

Componentes utilizados

01

ESP32

Microcontrolador responsável por processar as informações dos sensores, conectar-se à rede Wi-Fi e publicar os dados no broker MQTT.

02

DHT11 + MQ-135

O DHT11 mede temperatura e umidade, enquanto o MQ-135 fornece informações relacionadas à qualidade do ar.

03

Comunicação MQTT

O protocolo MQTT permite transportar os dados entre o ESP32, o broker Mosquitto e a aplicação Web.
