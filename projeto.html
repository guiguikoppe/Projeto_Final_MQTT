01
SOBRE O PROJETO

Qual é o objetivo?

O objetivo do projeto é desenvolver uma estação de monitoramento capaz de coletar informações do ambiente utilizando sensores conectados a um ESP32.

Os dados de temperatura, umidade e qualidade do ar são enviados pela rede Wi-Fi para um servidor MQTT. Depois disso, essas informações são disponibilizadas em um Dashboard Web, permitindo acompanhar os valores em tempo real.

O sistema também possui LEDs de alerta, que são acionados quando os valores dos sensores ultrapassam os limites definidos no projeto.

HARDWARE

Componentes utilizados

⚙️

ESP32

Microcontrolador responsável por controlar os sensores, LEDs, conexão Wi-Fi e comunicação MQTT.

🌡️

DHT11

Sensor responsável pela medição da temperatura e da umidade relativa do ambiente.

💨

MQ-135

Sensor utilizado para realizar a leitura relacionada à qualidade do ar e presença de gases.

🚨

LEDs de alerta

Indicadores físicos acionados quando os valores dos sensores ultrapassam os limites definidos.

04
MONITORAMENTO

Limites de alerta

🌡️ Temperatura Alerta acima de 28 °C
💧 Umidade Alerta acima de 56%
💨 Qualidade do ar Alerta acima de 400
